## 2026-10-08 응답 속도 회고

**회고 범위:** 연근 관련 YouTube URL 검증 1회 및 LangGraph 노드별 처리 시간 확인

| 단계 | 측정 시간 | 비중 |
|---|---:|---:|
| 추출 | 6.169초 | 63.5% |
| 검색 | 0.084초 | 0.9% |
| 읽기 | 3.394초 | 34.9% |
| 판정 | 0.051초 | 0.5% |
| 합성 | 0.001초 | <0.1% |
| 전체 | 9.718초 | 100% |

복구 재시도는 없었습니다. 판정과 합성 시간이 매우 짧아, 실제 판정·합성 모델 호출이 완료된 전체 경로의 기준 시간으로 보기는 어렵습니다.

| Continue – 계속 유지할 것 | Stop – 중단할 것 | Start – 새로 시도할 것 |
|---|---|---|
| 흐름도와 노드별 시간을 함께 확인해 지연 구간을 찾습니다. 검색 최대 횟수는 6회로 유지합니다. | 같은 조건에서 비교하지 않고 여러 방식을 한꺼번에 바꾸거나, 흐름도만 보고 원인을 추측하는 방식을 중단합니다. | 같은 입력으로 반복 측정하고 모델 호출·재시도·조기 종료 여부를 기록합니다. 확인된 병목인 추출과 읽기부터 하나씩 개선하고, 판정·합성이 실제 수행되는지도 확인합니다. |

**코드 변경:** 검색 최대 횟수를 6회로 맞췄습니다. 관련 검색 테스트 24개가 통과했습니다. 커밋 `aba107a`를 `feat/agent`에 푸시했습니다.
