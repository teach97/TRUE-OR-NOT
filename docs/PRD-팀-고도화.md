# TRUE-OR-NOT 팀 고도화 PRD

> 기준: `True_or_Not_고도화-기획서-v4.md` (as-built) + 세션 실측 (백엔드 289 passed, 프론트 54 passed, `tsc`·빌드 통과)
> 대상: 4명 팀, 킥오프 익주. v4의 P0/P1과 D1~D8을 닫고 시연 가능 상태로 만든다.
> 범위 밖: 로그인·보관함·공개 배포·정정 알림 (v4 후속 2/3, 조건부 제외)

## 1. 목표

1. v4의 높음·중간 한계(L1~L4)를 해소하거나 명시적으로 봉인한다.
2. D1~D8을 팀 결정으로 확정하고 코드·문서에 반영한다.
3. Q01~Q18 매트릭스를 전부 실행하고 결과를 기록한다.
