## 승인한 실제 호출 1회

- 프로젝트의 실제 `request_structured` 어댑터를 사용했습니다. 합성 연결 확인 입력만 보내고 폴백·재시도·추가 모델 호출은 수행하지 않았습니다.
- HTTP 200, 모델 `deepseek-v4.1-flash`, 공급자 `experiential_cloud`, `usage.is_byok=false`입니다. 입력 237·출력 29·총 266토큰이며 출력에는 추론 17토큰이 포함됩니다. 보고 비용은 $0.0001059입니다.
- 반환 JSON의 `reply`를 서버 모델로 검증했습니다. Windows Python의 CP949 출력이 UTF-8로 해석되어 한글 로그가 깨졌습니다. 요청한 문장 ‘연결 확인되었습니다.’의 동일 인코딩 역재현이 깨진 관측 문자열과 일치하여 표시를 복원했습니다. 원본 출력 바이트를 별도로 보존한 것은 아니며 다시 호출해 답변을 재생성하지 않았습니다. 이후 Python 시험 출력은 UTF-8로 지정합니다.
- Experiential 크레딧 경로 사용을 확인했지만 계정의 전체 잔액·다른 호출 비용·앞으로의 가용성·실제 사용자 질문 품질을 검증한 것은 아닙니다.
- 공식 기준: [모델 지원](https://platform.experientiallabs.ai/models/deepseek-v4.1-flash), [OpenAI 호환성](https://platform.experientiallabs.ai/docs/openai-compatibility), [비용 응답](https://platform.experientiallabs.ai/docs/cost-api). `store=false`를 모든 제공자의 무보관 보장으로 설명하지 않습니다.
