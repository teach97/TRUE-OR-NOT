## 별도 발견: 계산 오류

문서 정리 전 잔여 작업 조사에서 다음 입력을 네트워크 없이 직접 실행했다.

```python
extract_numbers("가격이 2,000원에서 2,500원으로 올랐다")
# 관측: [2500.0]
claim_computations("가격이 2,000원에서 2,500원으로 올랐다")
# 관측: []
claim_computations("매출 100억, 직원 130명")
# 관측: [{'expression': '100→130', 'percent': 30.0}]
```

[compute.py](../../../backend/compute.py)의 값 범위만으로 연도를 제외하는 규칙과 인접 숫자 자동 연결이 원인이다. 앞의 테스트 통과와 별개로 미수정 오류이며 [T13](../../작업현황.md)에서 관리한다. 가격 비교의 기대값은 25%이고 서로 다른 지표는 증감률로 연결하지 않아야 한다.
