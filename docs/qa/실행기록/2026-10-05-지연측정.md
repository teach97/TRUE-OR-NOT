# 2026-10-05 설정 고정 단일 지연 측정

결론: 실제 요청 1회는 1차 결과까지 33.53초, 최종 생성 실패까지 98.49초가 걸렸습니다. 판정·최종 생성이 전체 대기의 88.8%를 차지했습니다. 성공한 최종 답변의 완료 시간이나 여러 입력의 평균을 측정한 결과는 아닙니다.

## 범위와 방법

- 코드 기준: main의 `42f7d61`입니다. 질문은 비민감 예문 “인류는 달에 갔나?”이며 링크·이미지·과거 대화 없이 동의 true, JEV 빠른 경로 false로 실행했습니다.
- 사용자 요청에 따라 모델 종류와 추론 수준은 원인 분석·최적화 변수에서 제외했습니다. 기존 선택 `deepseek-v4.1-flash`, 추론 `max`, 공통 최소 출력 16,000토큰, 프롬프트·폴백·검색·재탐색·타임아웃을 그대로 유지했습니다. 이 설정값은 재현 조건이지 지연 원인의 결론이 아닙니다.
- backend의 실제 설정과 `classify_intent`·`make_runtime_adapters`·`build_runtime_workflow`·`stream_events`를 별도 Python 프로세스에서 실행했습니다. `RuntimeAdapters`의 단계 경계, `httpx.AsyncClient.request`, `runtime.fetch_public_text`에 임시 관찰 래퍼를 적용하고 `time.perf_counter()`로 측정했습니다. 요청·응답을 수정하지 않았으며 프로세스 종료 전에 원래 함수를 복원했습니다.
- 짧은 질문의 UI 흐름과 같이 intent가 verify로 분류된 뒤 검증을 시작했습니다. 다만 브라우저·Next.js intent/검증 프록시·사용자 화면 렌더링·DB 저장을 통과한 종단 간 시험은 아닙니다. 기존 서버 프로세스에는 관찰 래퍼를 설치하지 않았습니다.
- 실제 전체 경로는 정확히 1회 실행했습니다. 성공률 비교를 위한 추가 유료 요청·설정 변경·자동 재시도는 하지 않았습니다. 키·헤더·원시 응답·수집 원문은 출력하거나 저장하지 않았고 원문 읽기 로그는 URL 대신 짧은 해시 태그로 식별했습니다.

## 실패 경로와 판단

최종 HTTP 응답의 `choices[0].finish_reason`이 `length`였고 출력 사용량이 요청된 `max_tokens=16000`과 같았습니다. `backend/providers.py`의 `_experiential_text`는 stop이 아닌 응답을 `ProviderCallError("Incomplete response")`로 거부합니다. 이어 runtime이 SYNTHESIS_FAILED를 처리하고 스트림이 MODEL_FAILED 오류를 내보냈습니다. 기존 사용자 안내가 세부 종료 이유를 전달하지 않는 상태는 그대로입니다.

- 이 사례의 직접 실패 원인은 불완전 종료 응답이 성공 조건을 만족하지 못한 것입니다. 90초 단일 호출 제한이나 240초 전체 스트림 제한 도달은 아닙니다. 기존 16,000토큰 보완은 이 사례의 완료를 보장하지 못했습니다.
- 느린 구간은 판정과 뒤이은 별도 최종 생성입니다. 두 작업은 직렬이며 각각 자료를 모델 입력으로 구성합니다. `verification.py`와 `answer_synthesis.py`는 각 출처 본문 최대 6,000자를 각자의 입력에 넣으므로 원문을 다시 전달할 수 있지만, 서로 다른 판정/서술 목적을 가지므로 무조건 불필요한 중복이라고 단정하지 않습니다.
- 검색/일반 웹 읽기/전환이 이번 98.49초의 주된 비중은 아니었습니다. 원문 읽기 내부 처리의 추가 시간은 별도 관찰 대상으로 남깁니다.
- NDJSON은 단계·출처·preview를 먼저 전달하지만 최종 답변 본문은 합성과 검증을 마친 뒤 전달합니다. 따라서 preview 이후 64.96초 동안 최종 본문을 기다리는 구조입니다. 본문 스트리밍은 체감 대기를 개선할 수 있어도 완료 시간 단축 자체를 증명하지 않습니다.
- 다음 조사에서는 모델·추론 설정을 유지하고 호출 수, 판정에서 합성으로 전달하는 자료량/중복, 내부 후처리를 검토합니다. 근거 검증·출처 독립성 검사를 생략하거나 파이프라인을 합치는 수정은 이번 작업에서 하지 않았습니다.
