# 2026-10-05 대화 저장 선택·안내 위치 실행 기록

범위: 사이드바의 저장 체크박스·안내를 제거하고 최초 동의 창과 웹 하단으로 이동한 UI 보완입니다. 로그인·DB 재생성·백엔드 계약·보관 정책 변경은 포함하지 않습니다.

## 구현

- 데스크톱·모바일 `ConversationHistory`에는 대화 목록·복원·삭제·저장 오류와 재시도만 남깁니다.
- 최초 전송 동의 창의 저장 선택은 기본 꺼짐이며 외부 전송 동의와 별개입니다. 체크 상태는 임시 선택이고 ‘동의하고 시작’으로 확정한 뒤 보류한 요청을 제출합니다.
- 거절·닫기는 입력과 기존 저장 설정을 유지합니다. 하단 ‘대화 저장 설정’의 ‘설정 저장’은 저장만 변경하고 외부 전송 동의나 요청 제출을 수행하지 않습니다. 취소·닫기는 적용하지 않습니다.
- 개인정보 처리방침의 `conversation-storage` 항목에 저장 안내와 설정 경로를 모았습니다. 하단 링크는 해당 항목을 새 탭에서 열어 현재 대화·입력을 유지합니다.
- 새로고침 시 새 메시지 저장은 기본 꺼짐으로 돌아가며 유효한 익명 쿠키로 기존 기록을 복원할 수 있습니다. 저장 해제는 기록 삭제가 아닙니다.

## 미실행·경계

- 실제 DB를 사용하는 `conversation_smoke.py`는 새 하단 설정 경로에 맞춰 수정했으나 이번 작업에서 실행하지 않았습니다. DB 저장 계약은 변경하지 않았고 실제 DB 회귀를 다시 완료했다고 표시하지 않습니다.
- 로그인·기기 간 동기화·공개 HTTPS·운영자·법적 검토·자동 삭제·백업 정책은 기존 잔여 범위입니다. 이 안내 배치를 법적 요건 충족으로 표시하지 않습니다.
- `AGENTS.md`와 비밀 설정은 수정하지 않았습니다. 작업 전 존재한 `next-env.d.ts` 상태와 빈 미추적 `next` 파일은 이번 커밋 대상에서 제외합니다.
