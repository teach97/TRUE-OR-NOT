# 2026-10-05 DeepSeek MAX 출력 한도 보완

범위: 확인된 DeepSeek 답변 합성의 출력 한도 부족을 수정합니다. MAX 추론, 기존 GPT/Gemini·검색·인용 검증·폴백 정책·NDJSON·90초 호출 제한은 유지합니다. 재시도·오류 분류·새 환경 변수는 추가하지 않습니다.

## 진단 근거

- 기존 서버 로그에서 `SYNTHESIS_FAILED`가 GPT와 DeepSeek에 각각 1회 기록되었습니다. 최근 실제 검증 4회 중 2회의 실패 저장을 확인했습니다. 기존 로그는 상세 응답 종료 원인을 기록하지 않아 GPT 실패 원인은 미확정입니다.
- Experiential 읽기 전용 사용량·generation 조회에서 2026-10-05 20:19(KST) 호출은 입력 8,935, 출력 6,000, 추론 5,491토큰 및 `incomplete` 종료, 지연 약 43.9초를 보고했습니다. 서버 로그와 실패 메시지 저장 시각이 일치합니다. 해당 호출은 90초 타임아웃이 아니라 출력 예산 소진으로 판단합니다.
- 앞선 20:07 호출은 출력 3,091, 추론 2,379토큰 및 `stop` 종료를 보고했습니다. 게이트웨이 조회는 새 추론을 요청하지 않았습니다. 키·대화 원문·원시 응답은 기록하지 않습니다.
- [공식 호환성 안내](https://platform.experientiallabs.ai/docs/openai-compatibility)는 추론과 최종 답변이 `max_tokens`를 공유하며 부족한 한도가 `length` 종료를 일으킬 수 있다고 설명합니다. [모델 페이지](https://platform.experientiallabs.ai/models/deepseek-v4.1-flash)의 현재 기본 경로 최대 출력 393,216토큰은 이번 16,000토큰 설정보다 큽니다. 경로별 차이는 남아 있습니다.
