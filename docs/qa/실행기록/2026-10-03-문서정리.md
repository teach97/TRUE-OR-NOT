## 반영 범위

- docs 상단은 문서 안내·기획서·아키텍처·작업현황·배포 5개로 통합했다.
- 기존 Markdown 13개를 정리 직전 작업 트리 기준으로 archive에 보존했다. 본문·예상값·결과는 유지하고 과거 표시와 상대 링크 이동만 적용했다.
- QA 사례는 실행 JSON을 연결하고 날짜별 기록을 분리했다. mini 결과는 기존 날짜·내용 그대로 보존했다.
- 할 일은 T 번호, 결정은 D 번호로 통합했다. 모델·Render의 확정 사항과 미결정 정책을 구분했다.
- 루트 README의 문서 안내와 배포 링크를 수정했다. 지식그래프의 기존 문서 출처 경로는 archive로 옮기며 새 문서의 의미 추출을 수행한 것으로 표시하지 않는다.
