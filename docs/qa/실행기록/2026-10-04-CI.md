백엔드는 아래 명령으로 실제 키 환경변수를 해당 테스트 프로세스에서만 제외하고 DB 연결을 비활성화하였다. 개인 환경 파일·실행 중 서버의 환경은 수정하지 않았다.

```powershell
# backend 디렉터리에서 실행
& '.\.venv\Scripts\python.exe' -B -c "import os; names=['OPENAI_API_KEY','GEMINI_API_KEY','GOOGLE_API_KEY','YOUTUBE_API_KEY','TAVILY_API_KEY','SERPAPI_API_KEY','TYPESAFE_API_KEY','FINNHUB_API_KEY']; [os.environ.pop(name,None) for name in names]; os.environ['DATABASE_URL']=''; import pytest; raise SystemExit(pytest.main(['-q']))"
```

사전 실행에서 공급자 변수를 제거하지 않고 빈 값으로 설정했을 때 설정 파일 읽기 테스트 1개가 실패하였다. 빈 환경변수도 파일보다 우선하는 기존 설정 규칙 때문이었다. 문서의 변수 제외 방식으로 다시 실행해 343개 통과를 확인했으며 애플리케이션 설정 동작이나 테스트 기대값은 바꾸지 않았다.

## 정리와 미검증

- 테스트 발견 검증용 임시 파일을 제거하였다. 빌드가 생성한 `next-env.d.ts`의 경로 변경은 원래 개발 경로로 되돌렸다.
- 정리 후 타입 검사와 `git diff --check`를 다시 통과했고, 변경 문서의 로컬 링크 25개가 모두 존재함을 확인하였다.
- `graphify update .`로 코드·문서 구조 그래프를 갱신하였다(2,310개 노드·4,528개 간선, LLM 호출 없음). SQL 파서 미설치로 SQL 파일 1개가 인덱싱되지 않았고, 기존 노드의 `source_file` 누락 경고 22건이 남았다. 본문 의미 관계를 새로 추출한 것으로 해석하지 않는다.
- 이 검증에서는 웹·백엔드 서버를 시작하지 않았다. 기존 사용자 서버를 중단하지 않았다.
- 실제 LLM·검색·YouTube·Render DB 호출, 원격 UI·공개 배포 검증은 수행하지 않았다.
- T13 계산 오류와 나머지 미완료 작업은 작업현황의 남은 작업에 유지한다.

CI 액션 설정은 공식 [setup-node](https://github.com/actions/setup-node), [checkout](https://github.com/actions/checkout), [setup-uv](https://github.com/astral-sh/setup-uv) 문서와 실제 태그의 커밋을 확인하였다.
