# 판정 구조화 출력 임시 비교

- 일자: 2026-10-08
- 목적: 구조화 출력이 판정 단계의 응답 검증과 처리 시간에 미치는 영향 확인
- 코드 변경: 없음. `verify_claims`를 임시 입력으로 호출했습니다.
- 공급자: 자동 선택 첫 모델 `experiential/deepseek-v4.1-flash`
- 입력: 동일한 합성 주장과 검증용 고정 근거. 검색·읽기 단계는 실행하지 않았습니다.
- 제한 시간: 각 모델 요청 60초

## 비교 조건

| 조건 | 요청 방식 |
|---|---|
| 현재 구조화 방식 | 코드의 JSON 모드 사용, 스키마를 시스템 지시에 포함 |
| 비교 방식 | JSON 모드는 끄고 같은 스키마 지시는 유지 |

두 조건 모두 생성된 응답에 기존 `JudgmentResponse` 형식 검증과 서버 근거 검증을 적용했습니다.

- 평균 시간 차이는 0.15초로, 이 표본만으로 속도 차이가 있다고 볼 수 없습니다.
- 두 조건 모두 응답 형식과 근거 검증을 통과했습니다. 이번 비교에서는 구조화 출력이 검증 통과율을 높였다는 증거가 없습니다.

- 합성 입력 1종·조건별 2회인 임시 시험입니다. 실자료의 판정 정확도나 전체 워크플로우 시간 비교로 해석하지 않습니다.
