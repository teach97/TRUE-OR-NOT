# 2026-10-07 발표자료 글꼴 수정

## 범위

기존 발표자료에서 표지에 표시한 전체 발표 시간을 제거하고, 화면에 표시되는 시연 소요시간도 제거했다. PowerPoint에서 한글이 겹쳐 보인다는 보고에 따라 텍스트 도형 92개의 글꼴을 맑은 고딕으로 지정했다. 다른 문구와 슬라이드 구성 및 발표자 메모는 유지했다.

## 파일

- 수정 파일: `True_or_Not_전체소개_시연_15분이내_v2.pptx`
- 원본 백업: `True_or_Not_전체소개_시연_15분이내_v2.before-font-fix.bak`

## 검증

- Artifact Tool에서 수정본을 다시 불러오고 PPTX 구조·레이아웃 검사를 실행했다. 9장, 와이드 화면 크기, 글꼴 검사 및 가져오기가 통과했다.
- 전체 9장을 PNG로 렌더링해 개별 검토했다. 검토 렌더링에서 글자 겹침이나 잘림이 보이지 않았다.
- `slides_test.py` 결과: `Test passed. No overflow detected.`
- 파일을 수정 경로에 반영한 뒤 SHA-256이 검증된 수정본과 일치함을 확인했다.

## 미검증 범위

- PowerPoint 네이티브 앱에서 직접 열어 확인하지 않았다. 번들 렌더러로 보이는 결과와 네이티브 PowerPoint 글꼴 대체 결과가 다를 수 있으므로, 사용자가 PowerPoint에서 열어 최종 확인해야 한다.
- 실제 웹 서비스 시연과 Render 배포는 이 작업에서 다루지 않았다.
