# 2026-10-05 대화 저장 선택 유지 실행 기록

범위: 사용자가 승인한 동일 브라우저의 저장 선택 새로고침 유지입니다. 이전 [위치 이동 기록](2026-10-05-저장선택안내.md)의 새로고침 기본 꺼짐 동작을 변경합니다. 익명 소유권·DB·백엔드 계약·로그인·보관 정책은 변경하지 않습니다.

## 구현

- `ton_storage_consent`에는 별도 안내 버전만 localStorage에 기록합니다. 사용자 ID·소유권 쿠키·대화 본문은 넣지 않으며 외부 전송 동의 기록과 분리합니다.
- 최초 동의 창 및 하단 설정에서 확정할 때 기록합니다. 처음 사용·기록 없음·잘못된/이전 버전·읽기 차단은 꺼짐입니다. 취소·거절·닫기는 기록을 변경하지 않습니다.
- 브라우저 마운트 효과에서 선택을 복원하여 SSR 중 브라우저 저장소에 접근하지 않습니다. 다른 탭의 저장 해제·사이트 데이터 삭제는 선택을 동기화하고 신규 저장을 중단합니다. 같은 값을 반영할 때 진행 중인 대화 조회를 취소하지 않습니다.
- 쓰기 차단은 현재 화면에만 적용하며 확정 직후 화면에 경고를 유지하고 설정 창에서도 안내합니다. 이전 기록이 남아 있으면 새로고침 후 다시 적용될 수 있다는 제한도 안내합니다. 정상 저장 재시도 후에는 경고를 해제합니다. 저장 해제는 대화 기록 삭제가 아닙니다.
