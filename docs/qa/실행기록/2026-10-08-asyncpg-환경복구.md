# 2026-10-08 asyncpg 누락으로 인한 백엔드 실행 환경 복구

범위: `backend/.venv`로 Uvicorn을 시작할 때 발생한 `ModuleNotFoundError: No module named 'asyncpg'`를 해결했습니다.

- 원인: `backend/pyproject.toml`과 `backend/uv.lock`에는 의존성이 선언되어 있으나 실제 가상환경에는 설치되지 않았습니다. 해당 Python에서 `importlib.util.find_spec('asyncpg')`가 `None`인 것을 확인했습니다.
- 실행 환경: Windows, 프로젝트 `backend/.venv/Scripts/python.exe`, Python 3.11, uv 0.12.9입니다. 설치 옵션은 로컬 `uv sync --help`에서 확인했습니다.
- 복구 명령: 백엔드 디렉터리에서 `uv sync --locked --inexact`를 실행했습니다. 잠금 파일을 변경하지 않고 기존 추가 패키지를 보존했습니다. 의존성 62개를 확인하고 `asyncpg==0.31.0` 한 패키지만 설치했습니다.
- 모듈 검증: 동일 가상환경에서 `import asyncpg`와 `import main`이 통과했습니다. `asyncpg.__version__`은 `0.31.0`입니다.
- 서버 검증: 동일 Python으로 `uvicorn main:app --host 127.0.0.1 --port 8010`을 실행했습니다. `GET /health`는 HTTP 200과 `status: ok`, `service: factlens-backend`, `revision: a8e7a47-dirty`를 반환했습니다.
- 정리: 검증용으로 생성한 Uvicorn 프로세스만 종료했습니다. 작업 전 실행 중이던 프런트엔드 3000 포트는 유지했습니다. 서버를 사용하려면 백엔드 디렉터리에서 기존 Uvicorn 실행 명령을 다시 실행하시면 됩니다.
- 변경 범위: 앱 코드·`.env`·의존성 선언·잠금 파일은 수정하지 않았습니다. 프로젝트 지침에 따른 작업현황과 이번 실행 기록만 갱신했습니다.
- 미검증: 외부 LLM 및 PostgreSQL 접속, 대화 저장, 원격 배포는 확인하지 않았습니다. 환경 동기화 작업이므로 앱 단위 테스트·빌드는 추가 실행하지 않았습니다.
- Git: 기존 사용자 변경과 스테이징을 보존하며 이번 기록 두 파일만 로컬 커밋합니다. 원격 푸시는 앞선 보류 상태를 유지합니다.
