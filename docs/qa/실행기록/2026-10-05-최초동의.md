# 2026-10-05 최초 외부 전송 동의 실행 기록

범위: 사용자가 승인한 최초 1회 전송 동의(T11). 대화 저장 동의는 별도이며 실제 공급자·DB 호출·공개 배포·법적 검토를 완료로 표시하지 않습니다.

## 구현

- 첫 외부 호출 전에 대상·목적·수신 서비스 안내와 ‘동의하고 시작’ 선택을 제공합니다. 거절·닫기는 입력을 보존하며 전송하지 않습니다. 합성 예시·로컬 모델 안내는 외부 호출 없이 사용합니다.
- 동일 사이트·브라우저의 localStorage에는 원문 대신 안내 버전만 저장합니다. 다음 질문·새로고침에서는 유지하고 철회·사이트 데이터 삭제·안내 버전 변경 시 재확인합니다. 저장 차단 환경에서는 현재 화면에서만 유지합니다.
- 철회는 다음 요청을 차단하고 진행 중 요청의 취소를 시도합니다. 다른 탭의 철회·사이트 데이터 삭제도 반영하며 각 POST 직전과 늦은 응답 수신 후에 동의 기록을 재확인합니다. 이미 외부 서비스가 받은 정보를 회수하거나 삭제하지 않습니다.
- intent·검증·JEV·요약의 Next.js 프록시와 FastAPI의 다섯 외부 POST 경로에서 엄격한 boolean true를 검사합니다. 동의 확인 값은 로그인·소유권·위조 요청 방지 인증이 아닙니다.
- 개인정보 처리방침·약관·화면 안내에 실제 자막·JEV·intent·검색·요약 경로와 동의 유지를 반영했습니다. 운영자·수신국·제공자 처리/보관 조건·법적 검토는 T26에 남습니다.

## 독립 검토와 보완

- Important 2건·Minor 1건을 확인하고 모두 보완했습니다. 다른 탭의 철회 이벤트 도착 전에는 메모리의 동의가 오래될 수 있어, 제출·각 POST·응답 수신 후에 저장된 안내 버전을 재확인합니다. 저장이 차단된 환경의 화면 한정 동의는 별도로 구분합니다.
- 같은 화면에서 동의 기록만 삭제하여 이벤트 없는 경합을 실패로 재현한 뒤 통과했습니다. 응답을 보류한 의도 분석에서 같은 탭·다른 탭 철회 후 실제 `requestfailed` 취소 이벤트, 후속 POST 0회, 늦은 답변 미표시를 확인했습니다.
- 기존 intent의 본문·context·모델 입력 검증 시험에 유효한 동의를 넣어, 다른 검증이 깨져도 동의 누락 때문에 통과하는 것을 방지했습니다.
- 지적 범위의 후속 독립 검토에서 남은 지적 없음이 확인되었고, 실행자가 최종 FE 107개·BE 404개·타입·빌드·브라우저 회귀를 다시 실행해 통과했습니다. 검토자가 전체 시험을 재실행한 것으로 표시하지 않습니다.

브라우저 재현 파일은 `backend/tests/browser/external_consent_smoke.py`입니다. Playwright와 로컬 Chrome이 필요하며 `CONSENT_TEST_URL`에 시험 프론트엔드 주소를 지정합니다. 모든 API와 외부 주소를 인터셉트하므로 실제 공급자와 DB를 호출하지 않습니다. 사용자 브라우저가 아닌 임시 브라우저 컨텍스트만 사용·종료합니다.

## 실행 경계와 잔여 범위

- 기존 개발 프론트엔드와 같은 폴더의 임시 Next.js 서버가 충돌했습니다. 임시 실행은 종료하고 기존 개발 서버에서 모의 API로 시험했습니다. 시험 브라우저는 종료하고 임시 3018 포트 리스너 없음·기존 3000 프론트엔드 유지·8010 백엔드 재시작을 확인했습니다.
- 코드 커밋 `ccf0804` 이후 기존 백엔드만 같은 `127.0.0.1:8010` 설정으로 재시작했습니다. `/health`의 `status=ok`와 리비전 `ccf0804`, 동의 false인 실제 `/api/intent` 요청의 422 거부를 확인했습니다. 최초 생존 검사에서 존재하지 않는 `ok` 필드를 사용해 실패로 표시했으나, 실제 응답 계약의 `status` 필드로 재확인하였으며 서버 시작 실패가 아니었습니다. DB·비밀 설정·프론트엔드는 변경하지 않았습니다.
- 모바일 동의 창의 위치와 내부 가로 넘침을 직접 검사했습니다. 전체 페이지 폭 검사는 다른 화면 요소를 포함하므로 이번 동의 창 완료 기준과 구분했습니다.
- 브라우저 저장 차단 시 새로고침 뒤 재확인이 필요합니다. 동의 철회는 이미 처리된 외부 요청의 취소·정보 삭제·비용 환불을 보장하지 않습니다.
- 실공급자 연동·공개 HTTPS 환경의 통합 성공·운영자 정보·법적 처리 근거 검토는 별도 잔여 범위입니다. DB·비밀 설정·AGENTS.md는 수정하지 않습니다.
