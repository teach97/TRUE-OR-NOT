# True or Not 고도화 기획서 v4-요약

> v4 전체판(544줄)의 압축본. 상세는 원본 참조. 상태: v4 확정.

## 0. 한눈에 보기

**제품 정의.** 정답 선언이 아니라 주장과 근거를 추적·비교하는 생활형 검증 도구. 기사·댓글·텍스트에서 주장을 추출하고 원문과 검색 근거를 함께 제시하며, 확인된 것과 불확실한 것을 구분한다.

**현재 상태.** 텍스트·링크·이미지 입력 → 주장 추출 → 검색 → 원문 읽기 → 판정 → AI 개요 합성 5단계가 로컬에서 동작. JEV 빠른 경로(점수 전용) 병행.

**시연 전제.** 로컬 개발 서버 전용. 공개 배포 미지원 (POST 403 + loopback 고정).

**핵심 원칙.**
1. 검색 결과 부재를 거짓의 증거로 쓰지 않는다.
2. AI 설명을 원문 인용처럼 표시하지 않는다.
3. 출처 개수와 독립 근거 수를 혼동하지 않는다.
4. 근거 부족이면 결론을 유보한다.
5. 주장별 점수(0~100)는 부가 지표이며 단독 진실값이 아니다. 종합 평균·출처 품질 퍼센트는 표시하지 않는다. (D1 잠정안)
6. 처리 생략·실패를 "근거 부족"으로 표시하지 않는다.
7. 검색 스니펫·LLM 요약·유튜브 제목/댓글은 인용 근거로 쓰지 않는다. 원문 읽기와 인용 검증 통과 문구만 사용한다.

## 10. 기술 구성

- 브라우저 → Next.js 프록시(로컬 전용) → FastAPI 127.0.0.1:8010 → LangGraph 5단계 → NDJSON 스트림.
- 키는 `backend/.env` 전용. 브라우저에 키 없음.
- 제한: 본문/확인요청 12,000/500자, 주장 3개, 출처 6개, LLM 90초, Tavily 30초, 전체 스트림 240초, 재시도 없음(provider 폴백 최대 3단).
- 오류: INVALID_REQUEST, LOCAL_ONLY, BUSY, CANCELLED, NOT_CONFIGURED, AGENT_FAILED, BACKEND_UNAVAILABLE/FAILED, TIMEOUT, INTENT_FAILED, JEV 4종(LOW_CONFIDENCE·GATEWAY_ERROR·NO_JUDGMENT·BAD_RESPONSE).

## 14. 알려진 한계 (상위)

| ID | 내용 |
|---|---|
| L1 | JEV가 입력 전체를 사실 주장 1개로 고정. 의견·예측 오판 가능 |
| L2 | 동시 실행 제한이 메인 스트림에만. jev·intent 무제한이라 비용 위험 |
| L3 | 링크+문구 입력은 페이지 본문으로 폴백 (수정됨). 12,000자 초과 시 재검증 실패 가능성은 잔존 |
| L4 | 생략·실패가 "근거 부족"으로 표시됨 |
| L5 | JEV 두 갈래 (조용한 폴백 vs 502) |

## 15. 우선순위

| 우선 | 작업 |
|---|---|
| P0 | L1·L2·L3 확인과 수정, 테스트 수 감소 원인 확인 |

## QA 수용 기준 (발췌)

- 공백·상한은 전송 차단 + 이유 안내. 의견·예측은 검증 대상 아님.
- 검색 없음은 근거 부족으로, 장애와 구분해서 표시.
- 원문 없는 생성 인용은 제외하고 판정 재평가.
- Q17 링크·이미지 단독, Q18 JEV에 의견·예측 → 유형 미분류 또는 정상 처리.
- 타입·빌드 통과, "정확도 ○%" 홍보 금지.
