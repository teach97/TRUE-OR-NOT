# True or Not Render 배포

2026-10-03 결정: 배포 대상은 Render이며 Next.js 프론트엔드와 FastAPI 백엔드를 Docker 서비스 두 개로 구성합니다. `render.yaml`이 배포 설정의 기준입니다. 실제 서비스 생성·배포·원격 검증은 아직 수행하지 않았습니다.

## 구성과 환경 설정

| 서비스 | 설정 | 값·역할 |
|---|---|---|
| 백엔드 | Docker 컨텍스트 `backend`, `backend/Dockerfile` | `${PORT:-8010}`으로 바인딩, `/health` 생존·리비전 확인 |
| 백엔드 | `OPENAI_API_KEY`, `GEMINI_API_KEY` | 사용하려는 공급자 키. 적어도 하나 필요하며 없으면 설정되지 않은 공급자를 건너뜀 |
| 백엔드 | `TAVILY_API_KEY`, `TYPESAFE_API_KEY`, `YOUTUBE_API_KEY`, `FINNHUB_API_KEY` | 사용할 선택 기능에 맞춰 설정. 시장 데이터는 Finnhub 단일 어댑터 |
| 백엔드 | `BACKEND_SHARED_SECRET` | 프론트의 공유 시크릿과 같은 값으로 설정. `/health` 외 요청 헤더 보호 |
| 프론트 | Docker 컨텍스트 루트, `Dockerfile` | `${PORT:-3000}`으로 바인딩 |
| 프론트 | `FACTLENS_BACKEND_URL` | 실제 백엔드의 HTTPS URL. Blueprint의 예시 URL을 서비스 주소와 대조 |
| 프론트 | `FACTLENS_ALLOW_REMOTE_BACKEND=1` | 원격 HTTPS 백엔드 허용 |
| 프론트 | `FACTLENS_PUBLIC_DEPLOY=1` | 기본 로컬 전용 요청 정책을 공개 모드로 전환 |
| 프론트 | `FACTLENS_BACKEND_SECRET` | 백엔드 공유 시크릿과 같은 값. 서버 전용이며 `NEXT_PUBLIC_*`로 노출하지 않음 |

루트와 백엔드의 `.dockerignore`는 `.env*`와 로컬 가상환경·캐시를 제외합니다. 키는 Render 환경 설정에서 주입합니다. 공유 시크릿은 프록시↔백엔드 보호이고, 사용자 인증·호출 한도·외부 전송 동의가 구현되었다는 의미는 아닙니다.

## 구현 상태와 남은 검증

- 현재 메인 프록시만 프로세스당 동시 1건을 제한합니다. JEV·intent·summary 제한과 공개 이용자 접근·비용 정책은 추가 결정·보완 대상입니다. 프로세스별 메모리 제한은 여러 인스턴스 전체의 공통 제한이 아닙니다.
- 검증·JEV·요약 API는 `consent=true`를 검사하지만 화면은 이를 자동 입력합니다. intent에는 동의 계약이 없습니다. 실제 사용자 동의와 외부 전송 순서를 연결하는 작업은 남아 있습니다.
- 검증 그래프는 접근·인용 오류와 근거 부족이 함께 있을 때 최대 1회 재탐색합니다. 일반 근거 부족·의견·예측은 자동 재실행하지 않으며, 전체 스트림 240초 제한은 다시 시작하지 않습니다.
- 무료 인스턴스의 휴면·재시작과 외부 API 권한·쿼터는 실제 선택한 요금제에서 확인합니다. 영속 작업 큐나 재시작 후 작업 복구는 현재 제공하지 않습니다.

## 배포 완료 기준

1. 두 Docker 컨텍스트와 이미지에 비밀 파일이 포함되지 않는지 확인합니다.
2. 두 서비스가 시작되고 `/health`의 코드 리비전이 배포 대상과 일치하는지 확인합니다. 생존 응답만으로 모델 연결 성공을 판단하지 않습니다.
3. 잘못된 공유 헤더의 백엔드 호출이 차단되고, 올바른 프론트 요청이 실제 백엔드에 연결되는지 확인합니다.
4. 공개 접근·한도 정책과 사용자 동의를 정하고 외부 호출 전에 적용되는지 확인합니다.
5. 정상 검증·근거 부족·처리 실패, NDJSON 단계 전달, 최대 1회 재탐색, 시간 초과·취소·재요청을 원격에서 확인합니다.
6. 발표용 입력·영상·종목만 실제 호출하고 결과·실제 모델·실행 조건·제약을 기록합니다. 모의 테스트를 실공급자 성공으로 표시하지 않습니다.

이 기준을 통과하기 전 상태는 배포 준비·검증 대기입니다. 이 문서 갱신으로 실제 Render 서비스가 생성되지는 않습니다.
